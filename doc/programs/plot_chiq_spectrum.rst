plot_chiq_spectrum
==================

.. code-block:: bash

    plot_chiq_spectrum.py [-h] [--input_file_prefix INPUT_FILE_PREFIX] [--ielem IELEM]
                          [--wmin WMIN] [--wmax WMAX] [--part {real,imag}]
                          [--output_file_prefix OUTPUT_FILE_PREFIX] [--format FORMAT]
                          [--data_out DATA_OUT]
                          file_qpath [dir_chiqw]

Description
-----------

``plot_chiq_spectrum.py`` is a script for plotting the frequency-dependent susceptibility :math:`\chi(q,\omega)` along a q-path as a color map. This script creates a 2D plot where the x-axis represents the q-path and the y-axis represents the frequency :math:`\omega`.

Positional Arguments
---------------------

**file_qpath**
    File name for the q-path data, e.g. ``"q_path.dat"``, generated by ``gen_qpath.py``.

**dir_chiqw**
    Directory containing the input files. This is usually the output directory of ``chiq_anacont.py``.
    Default is the current directory (``"."``).

Options
-------

**-h, --help**
    Show this help message and exit.

**--input_file_prefix INPUT_FILE_PREFIX**
    Prefix of input file names. Default is ``"chi_q_w"``.
    The script expects files named as ``{prefix}_{q}.dat`` where ``{q}`` is the q-point in format "XX.YY.ZZ".

**--ielem IELEM**
    Index of the element to plot. Default is ``0``.
    This corresponds to the element index in the susceptibility matrix.

**--wmin WMIN**
    Minimum frequency to plot. If not specified, all available frequencies are included.

**--wmax WMAX**
    Maximum frequency to plot. If not specified, all available frequencies are included.

**--part {real,imag}**
    Part of the susceptibility to plot. Choices are ``"real"`` or ``"imag"``. Default is ``"real"``.

**--output_file_prefix OUTPUT_FILE_PREFIX**
    Base name for output files. Default is ``"chi_q_w"``.
    The script generates files with extensions specified by the ``--format`` option.

**--format FORMAT**
    Output format(s) for the plot. Multiple formats can be specified as comma-separated values (e.g., ``"pdf,png"``).
    Formats supported by savefig() of matplotlib.pyplot are available.
    Default is ``"pdf"``.

**--data_out DATA_OUT**
    Filename to write the numerical data as a text file.
    If specified, the script outputs the data in the format: ``x(q) omega Re[chi(q,omega)] Im[chi(q,omega)]``.
    If not specified, no data file is written.

Input File Format
-----------------

The script expects input files named as ``{prefix}_{q}.dat`` for each q-point along the path.
The format of these files is the same as the output of :ref:`chiq_anacont`

Output Files
------------

For details of the output files generated by this script, see :ref:`output`.

Examples
--------

Basic usage with default settings:

.. code-block:: console

    $ plot_chiq_spectrum.py q_path.dat

    Running plot_chiq_spectrum.py
    Namespace(file_qpath='q_path.dat', dir_chiqw='.', input_file_prefix='chi_q_w', ielem=0, wmin=None, wmax=None, part='real', output_file_prefix='chi_q_w', format=['pdf'], data_out=None)
    qlabels = [(0.0, 'X'), (0.5, 'Gamma'), (1.20711, 'M'), (1.70711, 'X'), (2.06066, "M'")]
    # of q points 57
    # of w points 201
    Figure saved to chi_q_w.pdf

Plotting imaginary part with frequency range and data output:

.. code-block:: console

    $ plot_chiq_spectrum.py q_path.dat --part imag --wmin 0.0 --wmax 10.0 --data_out chiq_spectrum.dat

    Running plot_chiq_spectrum.py
    Namespace(file_qpath='q_path.dat', dir_chiqw='.', input_file_prefix='chi_q_w', ielem=0, wmin=0.0, wmax=10.0, part='imag', output_file_prefix='chi_q_w', format=['pdf'], data_out='chiq_spectrum.dat')
    qlabels = [(0.0, 'X'), (0.5, 'Gamma'), (1.20711, 'M'), (1.70711, 'X'), (2.06066, "M'")]
    # of q points 57
    # of w points 101
    Data written to chiq_spectrum.dat
    Figure saved to chi_q_w.pdf

Multiple output formats:

.. code-block:: console

    $ plot_chiq_spectrum.py q_path.dat --format pdf,png --output_file_prefix chi_spectrum

    Running plot_chiq_spectrum.py

    qlabels = [(0.0, 'X'), (0.5, 'Gamma'), (1.20711, 'M'), (1.70711, 'X'), (2.06066, "M'")]
    # of q points 57
    # of w points 201
    Figure saved to chi_spectrum.pdf
    Figure saved to chi_spectrum.png
