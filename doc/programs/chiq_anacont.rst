chiq_anacont
============

.. code-block:: bash

    chiq_anacont.py [-h] [--version] toml

Description
-----------

``chiq_anacont.py`` is a script for performing analytic continuation of the susceptibility from imaginary frequencies to real frequencies. This script reads the susceptibility data in Matsubara frequencies from the output of ``chiq_post.py`` and performs analytic continuation using either the Padé approximation or the Sparse Modeling (SpM) method.

The script supports two methods for analytic continuation:

1. **Padé approximation**: A simple and fast method that constructs a rational function to interpolate the data from imaginary to real frequencies.
2. **Sparse Modeling (SpM)**: A more sophisticated method that uses sparse modeling techniques to perform analytic continuation with better accuracy, especially for noisy data.

The script processes each q-point and eigenvalue separately, performing analytic continuation for each component of the susceptibility tensor.

Positional Arguments
---------------------

**toml**
    Parameter file in TOML format. The script reads parameters from the ``[chiq_anacont]`` section. See :ref:`input` for details.

Options
-------

**-h, --help**
    Show this help message and exit.

**--version**
    Show version information and exit.

Configuration Parameters
------------------------

The parameters for ``chiq_anacont.py`` should be specified in the ``[chiq_anacont]`` section of the TOML file. For detailed parameter descriptions, see :ref:`input`.

The input file containing the susceptibilities in Matsubara frequencies is specified by ``input_file`` in the ``[chiq_anacont]`` section.
It is supposed that this file is under the directory specified by ``output_dir`` in the ``[chiq_post]`` section.
Hence, users usually need to specify only the filename without the path.

Example
-------

Basic usage:

.. code-block:: console

    $ chiq_anacont.py parameters.toml

Example of the TOML configuration:

.. code-block:: toml

    [chiq_anacont]
    input_file = "chi_q_eigen.dat"
    output_dir = "anacont_output"
    output_prefix = "chi_q_w"
    wmax = 10.0
    wmin = 0.0
    wnum = 101
    method = "pade"
    eta = 0.01

Example output:

.. code-block:: console

    $ chiq_anacont.py parameters.toml
    anacont_output/chi_q_w_00.00.00.dat is saved
    anacont_output/chi_q_w_00.01.00.dat is saved
    anacont_output/chi_q_w_00.02.00.dat is saved
    ...

The output files contain the real and imaginary parts of the susceptibility at real frequencies:

.. code-block:: none

    # Format: w Re[chi_1] Im[chi_1] Re[chi_2] Im[chi_2] ...
    -10.000000 0.123456 0.789012 0.234567 0.890123 ...
    -9.980000  0.124567 0.790123 0.235678 0.891234 ...
    ...

.. note::

    The script uses MPI for parallel processing when multiple processes are available. Each process handles a subset of q-points to accelerate the computation.

    For the Padé method, the parameter ``eta`` controls the small imaginary part added to real frequencies, which helps avoid singularities in the rational function.

    For the SpM method, ``loglambda`` controls the strength of L1 regularization. Lager values (more positive) lead to sparser solutions but may reduce accuracy.

    The input file should be generated by ``chiq_post.py`` and contain the susceptibility eigenvalues in Matsubara frequencies for each q-point.
